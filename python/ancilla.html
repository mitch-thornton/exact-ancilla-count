Line requirement, spectral front end

How many garbage outputs, circuit lines and constant inputs will a reversible embedding of this function need? Computed from the Walsh spectrum, not from the truth table.

The analysis classifies each support-disjoint component by randomized difference tests and routes it to the matching closed form. Where a class is established you get the exact garbage requirement g, the line count L = m + g and the ancilla count a = L - n. Where none is, you get bounds that always hold, and the tool says so rather than guessing. Most real circuits are high degree and land in the second case. The independence estimate is reported for information and is not a bound: on a one-hot decoder it excludes the true value.
